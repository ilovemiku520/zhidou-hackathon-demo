# 知斗桌面演示工具

知斗是一款面向知乎生态的知识互动与策略卡牌产品。本工具用于演示其核心功能，桌面运行方式仅是本次参赛的演示载体。

适用于Windows 10／11 64位，使用Chrome或Edge浏览器显示界面。包内包含运行组件，不需要安装Node.js、Python或浏览器扩展，不需要管理员权限、账号密码或云服务器。

1. 下载发布页中的`知斗demo演示文件.zip`，完整解压到可写目录，建议放在D盘。不要直接在压缩包中运行。
2. 双击“开始试玩.cmd”，会自动在默认浏览器打开本机页面。首次启动通常只需几秒；浏览器建议使用Chrome或Edge最新版。
3. 签到领取活力币，在鱼干批发买卖小鱼干。右上角开发者工具直接开放，可把小鱼干调为1,000继续测试。
4. 开始标准对战，或进入两个关卡、探索示例题单寻找暗黑看山。终局可复制战报，查看本地战术统计。
5. 退出时打开“试玩说明”，点击“保存并退出”。只关闭浏览器页不会结束本机进程；重新双击启动可回到原进度。

存档保存在本目录`data/zhidou-demo.sqlite`。它只有一份本地试玩进度，不关联知乎账户，不上传数据。重置按钮会清空这份进度；删除整个解压目录即可移除客户端，删除前请先退出。不要覆盖运行中的文件，升级时先退出并保留data目录。

核心功能可离线使用；联网时可阅读知乎活动官方公开知识，失败时提供原创玩法读本。示例题单不等于实时热榜，战术统计不等于知乎AI复盘。真实打赏、官方兑换权益、OAuth及真人匹配属于产品后续规划。

若未自动打开浏览器，可查看`data/startup.json`中的origin本机地址。启动失败请查看`data/startup-error.txt`，确认完整解压、目录可写且未运行另一份相同目录的客户端。该包为参赛便携工具，未做安装器及代码签名；受组织策略管理的设备可能不允许运行。

## 源码构建

开发环境使用Node.js 22.17.1或更高的22.x版本。进入desktop目录执行`npm ci`和`npm run build`。Windows默认输出到`D:/知斗测试/知斗demo演示文件`，其他环境默认输出`dist/zhidou-demo`。可用`ZHIDOU_DESKTOP_OUTPUT`指定输出，用`ZHIDOU_NODE_DIR`指定包含node.exe和LICENSE的Windows运行时目录。运行时从Node.js官方来源取得，保留其完整许可证。

构建复用site目录的页面和规则，使用desktop目录的单份本地存档适配。无需安装原网站部署依赖，也无需填写任何API密钥。`npm test`验证本地HTTP边界、存档及核心操作。
