## 可直接用于表单的简介

知斗是一款面向知乎生态的知识互动与策略卡牌产品，以活力币和小鱼干连接知识贡献、社区支持与游戏体验。用户完成日常任务、发表优质回答获取资源，在鱼干批发按每日概率报价买入、持有或卖出小鱼干，承担价格涨跌与手续费带来的盈亏；也可以用小鱼干打赏答主、参与对战或兑换官方头像框、称号和小礼品。参与官方活动后领取兑换码，将活动奖励带入产品。暗黑看山每日在热榜候选问题中为每位用户独立随机确定藏身位置，找到后可挑战。终局战报和战术复盘为用户自行分享讨论提供具体素材。

上述内容是完整产品设计。本次通过Windows桌面工具演示已完成的概率交易、钱包、任务、卡牌、关卡、示例题单Boss、彩蛋码和本地统计，免登录且开发者调币直接开放。真实回答核验、打赏转账、官方活动发码、礼品发放及知乎AI复盘尚未接通，完整流程与实施条件在产品计划书中说明。

## 运行环境和安装步骤

Windows 10／11 64位，Chrome或Edge桌面浏览器建议使用最新版。包内包含运行组件，不需要安装Node.js、Python或浏览器扩展，无需账号密码。手机、macOS和Linux不在本包支持范围。

1. 从发布页下载完成构建的“zhidou-demo-windows-x64.zip”，完整解压到可写目录，建议放在D盘。
2. 双击“开始试玩.cmd”，浏览器会自动打开本机操作界面；不要直接双击index.html或在压缩包内运行。
3. 领取每日任务奖励，在鱼干批发交易，使用随机搭档参加对战，再探索题单挑战Boss。开发者工具可直接调整小鱼干；结束后在“试玩说明”点击“保存并退出”。关闭页面不会自动结束本机程序。
