# 世界观与角色

四只看山醒在一座熟悉的海边城市：盐潮还未失控，病人仍在诊所休养，出海的朋友也仍有归期。他们以为自己穿越到了遗憾发生之前，直到灯塔公告说明，这里只是原世界片段拼接出的映像，原来的事故并未改变。

灯塔中的“未落之星”据说能实现愿望。四只狐获得由智晶与盐凝成的“盐忆”，它既保存过去的映像，也承载世界知识，并使其中的力量在对战中短暂显现。两只狐组成搭档，以攻防试炼争取许愿的机会。故事保留一个秘密：遗物只能再造映像，无法改写原世界。
