# 产品设计与演示范围

知斗是面向知乎生态的知识互动与策略卡牌产品。桌面工具只承载本次演示，产品设计以两种货币的获取、流通和消耗为主线。完整规则、数值示例、业务流程与实施条件见[产品说明计划书](产品说明计划书.md)，暗黑看山的随机降临规则见[降临机制](暗黑看山降临机制.md)。

## 演示已完成

每日概率报价的鱼干批发、双向交易与手续费、累计交易盈亏、钱包和对战收支、签到与阅读等任务、随机搭档卡牌对战、两个关卡、示例题单隐藏Boss、一次性彩蛋码、本地战报与统计。免登录、单份本地存档，开发者调整直接开放；官方公开知识可联网读取，离线提供原创玩法读本。

## 完整产品设计中的后续接入

| 模块 | 设计内容 | 接入条件 |
|---|---|---|
| 日常与优质回答 | 回答和互动领取活力币，达到字数及有效点赞门槛获得小鱼干 | 可靠身份、正文、互动及去重核验 |
| 读者打赏 | 任意读者向答主赠送小鱼干，不依赖系统奖励门槛 | 回答与身份关联，双方钱包一致转账 |
| 活动兑换码 | 活动核验后发码，限定账户、批次、期限和预算 | 官方活动合作及发码管理权限 |
| 官方礼品 | 头像框、称号、小礼品，包含库存、发放和退款 | 商品授权、真实库存及权益或实物履约能力 |
| 知识悬赏与服务 | 托管小鱼干，按交付、验收和争议规则结算 | 服务订单、验收及申诉流程 |
| 真人对战与财富榜 | 联网对战、正式账户总资产前100名 | 多用户存档、实时同步及公平性控制 |
| 热榜与AI复盘 | 真实问题候选池、个人随机降临、公开战报辅助分析 | 受保护的接口接入；原生页面入口另需平台支持 |

这些模块保留详细产品设计，不因演示未接入而从产品中删去。当前示例题单不是实时热榜，本地统计不是AI生成，彩蛋码不是官方活动发码；不向知乎账号发放虚构头像框或称号。

## 数值与使用边界

演示初始余额为测试补给；计划书中新增回答奖励和商品价格标为建议值，需要结合任务产出、对战净消耗及库存校准。功能验证不能证明长期数值已经平衡。参数调整不得回算已完成的订单或奖励。

货币仅用于本项目，不提供现金充值或提现。刘看山及相关标识属于原权利方，商品与形象使用按实际授权范围实施。代码和演示包不携带密钥、真实账户存档或私有用户资料。
